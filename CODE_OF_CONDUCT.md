# Code of Conduct

This is a friendly space for designers, planners, and brand teams, whatever their technical level.

- Be respectful. Beginners' questions are welcome.
- Give credit. Name the source of any idea, image, or prompt you share.
- Be honest about AI. Label AI-generated work and say where it fell short.
- No harassment, spam, or self-promotion unrelated to the repo's topic.

Maintainers may edit or remove contributions and block repeat offenders. Report concerns by opening an issue or contacting the maintainer directly.
